BLE Beacon Passworder
===========================

Features 
1) Blue LED in on solid except when
   A) Specific BLE Deacon is between -50 and -70 dBm then flash green LED
   B) Specific BLE Beacon is between  10 and -70 dBm then flash red   LED

2)   when Green LED is flashed, and button1 is pressed then send specified key presses over HID Keyboard


Note: Phone will need an app the tells Android to turn on BLE Beacon
